# HinoVerse — японский с полного нуля до свободного общения

> «Не просто учить язык. Начать думать на японском.»

HinoVerse — кроссплатформенное приложение (Android, iPhone, Windows, Linux, macOS, Web) для полного изучения японского языка русскоговорящими: от первого урока «что такое японский язык» до уровня JLPT N1. Приложение — устанавливаемое PWA, работает офлайн, синхронизирует прогресс между устройствами и использует Claude (Anthropic) для живых разговоров, проверки текстов и персонального плана.

### Честно о том, что пока не так, как в описании мечты

- **Голоса** — это синтезаторы речи устройства с разными настройками, а не записи носителей. Записи дикторов и видео можно добавить как контент без изменения кода.
- **Объём контента**: числа выше — реальные. До «700 глав и 35 000 уроков» курс растёт за счёт новых тем, историй и сцен (формат описан в `src/content/types.ts`).
- **Распознавание речи** зависит от браузера (Chrome, Edge, Safari). Анализ тона и ритма работает везде, где есть микрофон.
- **Город** — 2D-карта, а не 3D-мир; диалоги в нём — те же сцены, что и в разделе «Разговор», плюс свободный разговор с ИИ.

## Быстрый старт

Нужен Node.js 20+.

```bash
npm install
npm run dev        # интерфейс на http://localhost:5173
npm run server     # в соседнем терминале: API (ИИ и синхронизация) на :8787
```

Продакшен (один процесс раздаёт приложение и API):

```bash
cp .env.example .env     # укажите ANTHROPIC_API_KEY
npm run build
npm start                # http://localhost:8787
```

Или в Docker:

```bash
docker build -t hinoverse .
docker run -p 8787:8787 -e ANTHROPIC_API_KEY=sk-ant-... -v hinoverse-sync:/app/server/storage hinoverse
```

### ИИ (Claude)

- **Через сервер** (рекомендуется): задайте `ANTHROPIC_API_KEY` в `.env`. Ключ остаётся на сервере, приложение ходит в `/api/ai/*`. Встроено ограничение частоты запросов.
- **Свой ключ**: в «Настройках» → ИИ → «Свой ключ». Ключ хранится только на устройстве и не синхронизируется.
- Модель — `claude-opus-5-5`. Для живого диалога используется `effort: low` (быстрый первый ответ), для проверки текстов и плана — `medium` со структурированным выводом (JSON-схема). Включён серверный резерв (`fallbacks: "default"`): если основная модель отклонит запрос по правилам безопасности, API повторит его на рекомендованной резервной модели.
- Без ключа всё остальное работает офлайн, а разговоры идут по сценариям.

### Синхронизация

Сервер хранит прогресс в `SYNC_DIR` (по умолчанию `server/storage`) по коду вида `HV-XXXXX-XXXXX`. Слияние: карточки — по последнему повторению, уроки — по лучшему результату, опыт — по дням. Ключ API никогда не отправляется на сервер.

## Платформы

- **Web, Android, iPhone, Windows, macOS, Linux** — установка PWA: Chrome/Edge «Установить приложение», Safari «На экран „Домой“». После первого запуска уроки работают без интернета; словари кэшируются при первом открытии.
- **Нативные сборки** (магазины приложений) из того же кода:
  - Android/iOS — [Capacitor](https://capacitorjs.com): `npm i @capacitor/core @capacitor/cli @capacitor/android @capacitor/ios && npx cap init HinoVerse ru.hinoverse.app --web-dir dist && npx cap add android && npx cap add ios`, затем `npm run build && npx cap sync`. В настройках приложения укажите адрес сервера, а на сервере — `CORS_ORIGIN=capacitor://localhost` (iOS) или `http://localhost` (Android).
  - Windows/macOS/Linux — [Tauri](https://tauri.app): `npm create tauri-app` с `frontendDist: ../dist`.
- Для хостинга в подкаталоге (например, GitHub Pages): `BASE=/HinoVerse/ npm run build` (статическая часть работает без сервера; ИИ — через «свой ключ»).

## Устройство проекта

```
src/
  core/        ядро: FSRS, кана/ромадзи/Поливанов, спряжение и деинфлексия, проверка черт,
               анализ тона (YIN), речь, сравнение ответов, синхронизация, ИИ-запросы, план преподавателя
  content/     учебный контент: введение, кана, заметки к кандзи, ключи, грамматика N5–N1,
               темы, истории, сцены, диалекты, быстрые события, письменные задания, структура курса
  components/  фуригана, озвучка, анимация и проверка черт, ввод каной, проверка произношения,
               проигрыватель упражнений, перевод по нажатию, быстрые события
  features/    страницы: главная, курс, урок, повторение, кана, кандзи, словарь, грамматика, чтение,
               произношение, разговор, письмо, город, экзамены, преподаватель, диалекты, настройки
  store/       состояние и прогресс (zustand + localStorage)
server/        Node-сервер: раздача приложения, ИИ-прокси, синхронизация
scripts/data/  сборка открытых словарей в public/data (Python 3, только стандартная библиотека)
tests/         модульные и интеграционные тесты (vitest)
```

Команды: `npm test` — тесты, `npm run typecheck` — проверка типов, `npm run data` — пересобрать данные из источников (скачиваются автоматически в `scripts/data/.cache`).
